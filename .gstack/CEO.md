# GStack CEO Role Specification

## Vision & Product Mission
Antigravity Skill Recorder CLI empowers software engineers and AI developers to capture real-world interactive workflows (CLI commands, window contexts, narration) and instantly transform them into production-ready **Google Antigravity AI Agent Skills** (`SKILL.md`).

## Strategic Objectives
1. **Developer Velocity**: Eliminate repetitive manual prompt engineering by deriving skills from 1-shot session recordings.
2. **Standardization**: Enforce strict Google Antigravity Skill formats with YAML frontmatter, execution policies, and helper scripts.
3. **Cross-Platform Excellence**: Seamless operation across Linux, macOS, and Windows environments.
