# Contributing to Antigravity Skill Recorder CLI

We welcome contributions! Please follow these guidelines:

1. Fork the repo and create your feature branch: `git checkout -b feature/my-feature`.
2. Ensure TypeScript compiles without errors: `npm run build`.
3. Run test suites: `npm test`.
4. Ensure GStack standards pass: `node ./dist/cli.js gstack-review`.
5. Open a Pull Request with clear description of your changes.
